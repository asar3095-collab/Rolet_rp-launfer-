# RoleT RP — серверный режим

Это отдельная заготовка игрового режима SA-MP на Pawn. Файлы Arizona не изменяются.

## Файл
- `gamemodes/RoleT.pwn` — исходный код нового режима.

## Что уже заложено
- Регистрация и вход через диалоги.
- Сохранение аккаунта в `scriptfiles/RoleT_<ник>.ini`.
- Хеширование пароля через штатный native `SHA256_PassHash`.
- Начальные $5000 и 1 уровень.
- Команды `/stats` и `/help`.
- Точка появления в Лос-Сантосе.

## Важно перед запуском
1. Это стартовый каркас, а не готовый production-мод.
2. Он рассчитан на SA-MP 0.3.7 с поддержкой `SHA256_PassHash`.
3. Скомпилируй `RoleT.pwn` совместимым Pawn-компилятором в `RoleT.amx`.
4. Сначала тестируй на копии сервера. Не заменяй `Arizona.amx`.
5. Для переключения режима потребуется изменить значение `gamemode0` в `server.cfg` на `RoleT` и перезапустить сервер.
6. Не загружай исходники/пароли RCON в публичный репозиторий.

Дальше потребуется проверить компиляцию на точной версии серверных include-файлов и добавить систему работ, фракций, транспорта и базу данных.
